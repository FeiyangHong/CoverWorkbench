♫ 视频制作工作台

从混音到双语成片

  1. 新建英文名工程，或导入已有 video_config.toml。工程放在 projects/video/，原文件保留。

  2. 选择原视频与最终混音。也可以通过 yt-dlp 下载公开视频链接；首次使用前在工作台目录运行 powershell -ExecutionPolicy Bypass -File tools/InstallVideoTools.ps1。FFmpeg 与 FFprobe 在主工作台「环境设置」中配置。

  3. 测量响度与分段偏移。检查三个区间是否一致，再选择应用候选。正偏移表示混音应延后；同名歌曲的不同剪辑版也可能不匹配，不能只看一个数。

  4. 分别导入原文、译文 LRC / SRT / VTT（UTF-8）。选择字幕是对齐混音，还是已经对齐视频。不同时间轴按区间拆分配对；单文件可含多行文字。

  5. 原文歌词如果能对应已保存 SVP 的音节，可选择演唱轨生成时间锚点。逐句勾选确认后才改时间；重复句、读音、辅音提前等需要试听。不会自动翻译或回写 SV。

  6. 直接修改表中的开始、结束和双语文字。点击编号定位；在字幕样式页修改两种语言的字体、间距、位置、描边，也可只覆盖当前句。

  7. 用空格播放 / 暂停，I / O 设置入出点，勾选循环反复试听。准确预览最多 30 秒，与导出共用 FFmpeg / libass，包含实际音频处理；快速布局仅作草稿参考。

  8. 导出页选择尺寸、帧率、MP4 / MKV 与 CRF。每次新建独立版本目录，附配置、ASS / SRT、解码 / 响度 / 哈希报告。任务可取消，原文件与旧成片保留。

完整导出保留原视频长度；超出结尾的音频会裁切。响度提升可能改变动态，必须确认后再发布。网页不提供剪映原生工程、自动翻译或任意多轨视频剪辑。

文件夹中的 project.json 是当前工程，History/ 是旧配置，Sources/ 保存导入字幕 / 配置副本，Jobs/ 保存下载、分析、预览，Exports/ 保存正式版本。媒体一般以原路径引用；移动电脑时须一并复制媒体并重新选择路径。

下载仅在你主动提交时联网。不读取浏览器 Cookie。远端网站限制、登录与可用格式会影响下载；也可以使用已有本地素材。

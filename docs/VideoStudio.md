# 视频制作工作区

从主工作台上方或左侧「视频制作」进入，地址为本机 `/?tab=video`。左侧显示视频工程及新建入口，共用工作台的环境设置与彻底退出。视频文档独立管理，不要求先导入 SV 工程；音乐工作台与视频制作可以分别处理不同歌曲。

切到混音指南或音乐工作台会暂停视频试听；返回时保留未保存草稿、播放位置、缩放与撤销记录。切换视频工程前自动保存当前草稿，保存失败则保留当前工程并提示。刷新整个网页仍会清空页面撤销记录，未保存草稿会触发离开提示。

可用 `/?tab=video&videoProject=My%20Cover%20Video` 收藏具体视频工程。原 `/video/index.html?project=...` 链接会自动打开主工作台中的同一工程。移动端在视频区内的工程下拉框切换；导出任务由后台继续处理。

## 编辑布局与预览空间

加载工程后顶部只保留工程操作和可展开的「步骤检查」；新建、切换工程、创建剪辑副本和说明收在「工程与帮助」中。主工作台的「专注编辑」可进一步收起上方导航与音乐关联栏，点「恢复导航」展开；页面不会重新加载，草稿与试听位置保留。

预览区顶部可切换「画面剪辑 / 字幕编辑 / 总览」。剪辑工程默认显示画面轨，普通 MV 工程默认显示字幕轨；需要同时查看时再选总览。字幕编辑时可单独开关字幕表，画面下方保留双语时间轴；桌面宽屏会固定预览画面，滚动字幕时仍可查看画面。用「画面大小」滑块调整预览高度；这些偏好按视频工程保存在本机浏览器，不写入字幕、样式、音乐或工程文件。

左侧拆为媒体库、参考/下载、声音、字幕、片段、样式和导出七个入口。媒体库在所有视频工程中可见，支持多素材导入；参考/下载用于对时参考视频及链接下载，声音用于混音路径/对齐/响度，字幕用于导入与 SV 时间锚点，片段用于画布时长/帧率/当前片段精确修剪。双击画面片段可打开片段设置。相关引导会打开对应面板，减少在一个长栏内上下查找。

网页转场使用已解码的画面缓存；跳转或缓冲期间保留上一幅有效画面，不反复清空画布，也不从解码回调再次发起跳转。缓冲提示不代表渲染失败。浏览器解码和设备负载仍可能使快速播放短暂停顿，最终编码与声音处理使用准确区间预览检查。

## 从一首歌进入对应视频

音乐页上方提供「创建关联视频 / 进入本曲视频」与「关联设置」。第一次可新建支持中文、日语和空格的视频工程，或选择已有工程建立关联；以后选择这首歌，再点视频入口即可回到它的视频。视频区顶部也可以选择对应歌曲建立关联，或返回这首歌。每首歌对应一个视频工程，每个视频也只关联一首歌；「视频库」仍可浏览其他独立视频。

新建时默认引用本曲最近一次已完成交付所用的音频；没有交付记录时使用登记的成品混音。不会用分离主声、伴奏或试听副本代替。窗口列出来源，可另选最终 WAV / FLAC 等文件，支持带引号的路径和文件浏览；应用后会为本曲记住手动选择，也可切回「自动选取」。没有混音仍可创建，分步引导会提示补齐。

字幕优先复制音乐侧**已保存**的双语时间稿；没有时读取带完整时间的歌词素材，明确标为「LRC 时间草稿（待校对）」。没有时间或译文时不会编造，也不会自动翻译；字幕对应演唱内容和成品混音的准确程度仍须试听。音乐页有未保存字幕时，窗口提供「保存字幕草稿并刷新」按钮。

**进入已有视频、建立或解除关联都不会替换视频素材与字幕。** 后续混音或音乐字幕变更时，在「更新素材 / 关联设置」明确选择带入混音、替换字幕，或两者一起更新。仅更新混音会保留视频已编辑的字幕时间、额外微调与样式，并要求重新检查对齐；替换字幕会用音乐侧时间稿替换文字和时间、重置旧字幕的逐句样式与额外微调，保留全局样式与音频偏移，旧配置保留在 `History/`。若视频音轨与音乐混音不同，必须同时带入混音才能替换字幕，避免把已经单独对齐过的音轨与另一种字幕时间基准混用。

新建带入的字幕记录为混音时间。首次加入 MV 后，当前音频偏移只计入一次；后续同一素材改变偏移只补差值。关联关系保存在忽略于 Git 的 `config/video-links.local.json`，前一版保存在同目录 `.previous.json`；不修改原始 SVP、Song、音频和歌词文件。关联使用本机绝对路径，迁移设备时仍需复制媒体并修正路径。

## 分步引导与自动检查

页面顶部提供六步引导：获取 MV → 导入混音 → 对齐声音 → 双语字幕 → 预览检查 → 导出成片。点击步骤可查看缺项并直接定位操作；已有项目可收起说明，为预览留出空间。

检查包括素材路径、可选下载依赖、FFmpeg/FFprobe、字幕时间基准与双语内容，以及当前版本是否已有准确预览/成片。对齐试听和预览观看由用户明确确认，程序不会把相关度或任务成功当作人工审校。素材、偏移、字幕、样式或处理参数变化后，相应确认与预览会失效；未保存草稿也会参与缺项提示。

## 时间基准与重复偏移保护

- **混音时间导入**：只在导入时添加一次当前音频偏移，保存字幕来源及关联素材。以后同一素材的音频偏移改变，保存时只补新旧差值。例如原来 +5 秒改成 +7 秒，字幕只再移 +2 秒；重复保存不会再移动。
- **视频时间导入**：字幕固定在视频坐标，改变音频偏移不会移动字幕。
- **字幕整体微调**：独立的额外调整。若与已计入的音频偏移相同，会提示疑似重复，准确预览/导出前须清零或明确确认；整体改时也会拦截常见的重复添加。
- 更换或覆盖视频/混音、旧工程没有时间来源记录时，引导要求重新确认字幕基准。确认“现有字幕已是视频时间”只登记当前坐标，不会再加偏移。
- 已经处理成对齐视频的音轨，可标记并锁定音频偏移为 0。需要恢复原始音轨偏移时，先取消标记。
- 新导出的字幕附带 `caption-timing.json`。原样重新导入时会识别其已经是视频时间，拒绝再次作为混音时间叠加。文件被搬走且缺少边车信息时仍须自行选对基准，程序不能凭歌词文字推断所有历史处理。
- 重新导入从源字幕重新生成时间，并清零旧的字幕整体微调；历史工程保留。

## 多素材画面剪辑 · 第一版

所有视频工程都显示媒体库。「参考视频」是单个对时参考或完整 MV，不是媒体数量限制。已有完整 MV 工程可以点媒体库内的「启用多素材剪辑」，在同一工程增加画面轨：保留字幕、样式、混音、音频偏移、字幕微调及音乐关联，原视频成为第一段，启用前版本保留在 `History/`。只有明确点击才转换，未保存稿先保存；转换会重新载入当前文档并清空页面撤销记录，之后的片段操作仍可撤销。

视频页仍提供「新建剪辑工程」和「以当前工程创建剪辑副本」。如果希望保留独立的完整 MV 工程，使用创建副本；它复制磁盘上已保存的字幕、样式、音频偏移和字幕微调，原视频作为一个完整画面片段进入新工程。原工程文件、音乐关联和旧导出不修改；未保存编辑须先保存。原视频的原有时长保留，不会自动裁成混音长度。

推荐操作：

1. 新建剪辑工程，选择最终混音并保存，点击「使用混音时长」。默认 16:9 / 1920×1080，帧率可选 24、25、30、60。
2. 在「媒体库 → 批量导入素材」选择多个视频、图片或音频。点击切换勾选，Shift 连选，也可全选当前文件夹、跨文件夹继续选择，最后点「导入所选素材」。按选择顺序逐项导入，单项失败不阻止其余项；「停止后续」不打断正在处理的文件。外部文件复制到当前工程 `Media/Video`、`Media/Images`、`Media/Audio`，保留原文件，按内容哈希避免重复复制。链接下载完成后，点「使用下载的视频」会把结果加入剪辑工程的媒体库，不替换整个画面。
3. 导入只收录素材，不改变画面轨。点「将本次 N 个画面依次加入末尾」可按导入顺序加入成功的视频/图片，整批支持一步撤销；也可逐张点素材的「加到末尾」。尚未启用剪辑时，这些操作会先保留当前工程内容并启用画面轨，原视频若已成为第一段不会重复添加。再用片段检查器设置素材入点、出点、持续时长和成片位置。支持完整显示 / 裁切填满，以及水平、垂直取景。图片可以任意设置持续时长，也可一键补齐所有画面空白。
4. 从媒体库直接拖动视频或图片的缩略图到画面轨指定位置，落点显示时间、占用范围与后续画面的预排位置。默认「插入排序」：新素材落在片段中间会保留左右两段的修剪和取景，腾出空间放入新素材，后续画面顺延；已有片段拖动到另一段的前半部 / 后半部则插在它之前 / 之后，原位置的后续画面接拢。需要放进空白而不顺延其他画面时，选「自由移动」；空间不足会显示红色提示，松手不覆盖原画面。音乐与双语字幕始终留在原时间。
5. 默认边缘吸附；Alt 临时关闭。画面轨可缩放、跟随播放头；下方仍保留独立原文 / 译文字幕轨，沿用单行编辑、文字编辑、吸附和撤销重做。片段编辑也可撤销、重做，保存后能继续撤销。
6. 缺少画面时界面明确标出空白长度。默认禁止带空白导出；使用图片补齐，或明确勾选「允许空白区间显示黑底」。音乐、原文和译文使用同一条成片时间，改画面不会触发字幕偏移补偿。拼接模式不使用整支 MV 的固定偏移估计，仍可单独调整音乐位置和原有字幕时间。
7. 先做准确区间预览，再完整导出。快速播放按同一份片段记录切换媒体，片段原声静音，播放最终混音。浏览器不支持的素材可点「网页代理」，生成本机 H.264 预览副本；导出仍使用原媒体。原始编码或网络磁盘读取可能使快速切换有短暂加载，准确渲染是最终检查依据。

渲染对视频与图片共用轨道层级、显示状态、片段、入出点、取景、帧率和画布记录，按统一帧边界拼接；仅处理所选预览区间，避免为几秒预览先渲染整首歌。中间画面使用无损编码，最终输出 H.264 + AAC，并复用现有 ASS/libass 字幕与响度处理。成功后清理本次画面中间文件；失败诊断和旧成片保留。当前支持最多 8 条画面轨、共 200 个片段、16:9 画布和同轨接点转场；画面采用整幅覆盖方式，尚无画中画、透明度混合、变速、关键帧和额外音效轨。

媒体库支持搜索、预览、缩略图、网页代理，以及「重新定位 / 替换引用」。重新定位保留片段位置和修剪范围；替代视频必须足够长且类型相同。只是从时间轴移除片段不会删除媒体库或源文件。`media-library.json`、代理、缩略图、媒体与真实剪辑工程全部保留在私有项目目录，不上传 Git。

### 拖放与插入排序

只拖到画面轨或上方标尺才会放置，拖到音乐轨、字幕轨或编辑区外不会修改内容。视频和图片可以拖放；音频仍由「设为混音」单独选择。普通 MV 工程须先「启用多素材剪辑」，出现画面轨后再拖放。键盘或触屏可先定位播放头，再点媒体卡片的「插到播放头」，使用同样的画面插入规则。

拖放支持帧对齐、播放头 / 片段边缘吸附和 Alt 临时关闭吸附；缩放后靠近左右边缘会自动水平滚动。拖动期间只是落点预排，松手才写入草稿，一次拖放对应一步撤销。Esc、指针取消、切换工程或离开工作区会取消尚未落下的操作，保留已有撤销 / 重做记录。仍可拖两侧修剪、分割、复制，或用前移 / 后移按钮换序；拖动不会修改源素材。

插入与接拢只改变目标画面轨，其他视频轨、音乐和字幕不顺移。多轨工程会在画面超出当前结尾时延长成片，已有片段换序保留成片时长；原单轨工程沿用插入时延长的规则。音乐不拉伸、不移动，原文与译文也不补加偏移。片头 / 片尾淡化仍跟随成片首尾。接点变化后，已经不成立的转场会移除，过长转场会缩短；需要在新的接点重新检查。拖放和「插到播放头」都可以 Ctrl+Z 撤销、Ctrl+Y 重做，并在保存后保留于工程。

### 连续缩略图与多条画面轨

时间轴默认开启「缩略图」。视频片段按实际素材入点连续取帧，放大时间轴后显示更密的画面；只处理当前可见区间，水平滚动后补充新区域。图片片段重复显示该图片。缩略图使用当前工程 `Cache/Filmstrips/` 下的缓存，需要 FFmpeg；后台最多同时处理两组，每组 8 帧，不扫描整段歌曲。首次生成时显示进度文字，失败不妨碍修剪；可关闭显示，或关闭再开启以重试失败项。离开视频工作区会清除尚未开始的排队项，已开始的一组可以完成并缓存。

点击「＋ 视频轨」添加上层轨道；选择「目标轨」后，素材添加、插入和补齐空白均作用于该轨。也可把素材直接拖到另一条轨，或上下拖动已有片段跨轨移动。跨轨移动保留落点时间、入点与时长，原位置留空；目标轨已有画面时会拒绝重叠，可以换到空白或其他轨道。同轨允许插入排序，跨轨允许时间并行。

屏幕越靠上的轨道，覆盖层级越高；某一秒有多个可见轨道时，采用最上层的整幅画面。上层空白时显示下层；「↑ / ↓」改变覆盖层级，「可见 / 已隐藏」切换参与预览和导出的状态，隐藏不删除片段。每轨可改名，只允许移除空轨。层级、隐藏、跨轨移动与轨道名均随工程保存并可撤销；「缩略图」仅为本机显示偏好。

快速预览、准确区间预览和完整导出使用同一层级与隐藏规则，原声监听选择当前最上层的可见视频；最终混音和双语字幕仍独立。转场只关联同轨相邻片段；被上层画面覆盖的下层转场不会透出来。所有轨道都没有可见画面的区间仍按空白处理，导出黑底须明确允许。

旧单轨工程默认显示为「视频 1」，打开时不自动保存或转换；新增轨道或更改轨道属性后才保存多轨配置。既有字幕、样式、音频偏移和源文件保持不变。此更新包含后台接口与工程校验，首次使用前请保存草稿、彻底退出，再重新启动工作台。

## 画面接点转场

在画面时间轴下方的「画面转场」区，选择两个相邻片段的接点，再选「交叉溶解」或「淡出至黑 · 再淡入」，输入总时长。已添加的转场在时间轴上显示色带，点击可直接选择并调整；直接拖动色带的左端或右端可对称改变总时长，接点不动。拖动时保持一个固定探查时间实时预览，松手提交为一次撤销记录；Esc、取消指针或窗口失去焦点恢复原时长。手柄聚焦后可用左右方向键微调，Shift 加大步长；选「直接切换」移除。支持撤销、重做和保存后恢复，「试听此接点」设置附近试听区间并从区间起点播放。

转场以原接点为中心，左右各占一半，**不重叠或挪动片段，不缩短成片，也不改变音乐、原文或译文的时间**。超出片段修剪范围的画面使用首尾帧延长，不会露出已经剪掉的素材。转场长度按偶数帧取整，最短两帧，最长 10 秒且不能超过相邻较短片段的长度；有空隙的片段之间须先接拢。修剪导致转场过长时自动缩短，改变相邻关系或产生空隙时移除相关转场并提示；这些变化同样可以撤销。

网页快速预览使用两层静音画面合成，包含相同的黑边/裁切和转场时间；准确区间预览和完整导出共用同一帧网格和 FFmpeg 转场渲染。即使从转场中途预览，也保留该时间点的实际进度。字幕在转场之后独立叠加，不会跟着画面淡出。浏览器解码或设备负载可能使快速播放短暂加载；需要检查最终编码、字体和声音处理时，使用「准确区间预览」。

## 片头淡入、片尾淡出

同一画面时间轴下方提供两个独立开关和秒数输入。启用后，「片头 / 片尾」一行显示淡化色带：片头固定在成片 0 秒，拖右端调整；片尾固定在成片终点，拖左端调整。支持实时预览、取消和一步撤销，与接点转场同样保存到工程。最长各 10 秒，至少两帧，二者总时长不能超过成片长度；改变帧率或缩短成片时会按帧重新限制。淡化范围内第一帧 / 最后一帧为黑色，作用于画面合成之后、字幕叠加之前，不淡化音乐或字幕，也不移动字幕、音乐、片段位置或导出长度。如果允许开头/结尾黑底空隙，淡化仍按成片首尾计时。

## 剪辑和原有视频制作的关系

两者在主工作台的「视频制作」里，共用工程列表、最终混音、字幕编辑/样式、准确预览和导出。原完整 MV 工程用于整段换音轨；剪辑工程额外包含媒体库、多条画面拼接轨、连续缩略图、转场和首尾淡化。它不是另一个网站，也不需要把剪辑结果导回旧界面再添加字幕。

已有剪辑副本可直接打开；原工程不自动转换或替换。新歌从「新建剪辑工程」开始，旧工程可以明确「启用多素材剪辑」以保留同一工程及音乐关联，或「以当前工程创建剪辑副本」以保留独立版本。页面「剪辑怎么用？」提供同一流程的展开说明。下载的视频必须点击加入媒体库，再放到画面轨；已有最终混音只引用/选择一次，已处理过的音频或字幕不要再次加偏移。

## 本地路径、原声与轨道显示

在「参考/下载 → 参考视频」粘贴路径后，按 **回车** 或点 **应用并加载**；混音路径也有同样入口。文件浏览器选中文件后直接应用。应用会保存当前草稿、校验路径并重载播放器；不存在的路径会就地报错，旧工程文件及源视频不会覆盖。剪辑工程中的此字段是对时参考视频，画面片段仍从媒体库添加，不会把当前剪辑自动替换为一整支 MV。

MKV / AVI 会准备 H.264 / AAC 网页兼容副本，保留可用音轨；媒体库新生成的代理也保留声音。原视频和原音轨始终保留，兼容副本只用于网页预览，准确预览和导出仍读取原素材。依赖本机 FFmpeg / FFprobe；处理失败会显示原因，不再把粘贴路径当作已经加载成功。

预览播放条的「试听音轨」可切换 **翻唱混音 / 原视频声音**。在剪辑模式中，原声随当前片段的入点和画面时间播放；图片与空白区间无原声，切换片段不移动音乐或字幕。转场画面保持静音合成，独立声音播放器负责原声监听，避免多份视频声音叠加；原声监听按片段接点切换，不对原声另做音乐交叉混合。选择原声只影响监听，成片仍使用工程中选定的翻唱混音。

预览上方 **轨道显示** 提供「全部轨道」「只看字幕」，也可单独开关画面概览、混音波形、原视频波形、原文和译文字幕。混音波形默认显示，原视频波形按需开启；波形和字幕共用同一时间轴缩放，点击波形可以定位。剪辑时间轴也可显示混音 / 原声波形。显示偏好仅保存在此浏览器，不写入字幕、音频偏移或导出设置。

波形是用于定位的单声道峰值包络，不是响度测量。音频监听、兼容视频和波形按源路径、大小、修改时间缓存于私有 `runtime/video-preview`；最多同时处理两个请求，波形按块解码，完成后不持续占用解码进程。源文件改变后重新应用路径即可生成新缓存；没有音轨的素材会明确提示。

## 一次制作

1. 新建工程名（支持中文、日语和空格；仅检查 Windows 文件名规则）。同名自动使用 `_v2`、`_v3`，不会覆盖。选择原视频和最终翻唱混音，支持带引号的 Windows 路径与按时间排序的文件浏览器。
2. 可主动通过 yt-dlp 下载 YouTube / Bilibili HTTPS 视频链接。完整视频以网站标题命名，直接保存到本工程 `Media/Video/`，不为每个视频另建下载目录；标题保留中文、日语和空格，Windows 非法字符替换为相近的全角字符。同名同内容复用，不同内容另存 `_v2`。只有点击「使用下载的视频」才更新工程素材；加入剪辑媒体库时直接登记项目内文件，不再复制第二份。下载不读取浏览器 Cookie，也不使用机器上的 yt-dlp 配置。网站限制与授权要求可能导致下载失败，可随时改用已有本地素材。
3. 「测量响度与分段偏移」比较原视频和翻唱。三个分段的多频带瞬态相关度给出固定偏移候选；结果不一致时须检查是否存在剪辑差异。此估计不是语音识别，也不是样本级同步保证，不会自动应用。正数表示混音延后。
4. 导入 UTF-8 LRC / SRT / VTT 原文与译文。LRC 的 `offset` 标签会计入，双语按独立时间区间配对，避免行数相同但实际错行。字幕若对齐混音，导入时加一次音频偏移；若已是视频时间，不加偏移。
5. 在表格修改字幕时间与文字。字体、字号、字间距、X/Y、颜色、加粗、描边、阴影可全局修改，也可覆盖单句。常见字体用“微软雅黑、黑体、宋体、楷体”等中文名称显示，点击“字形预览与选择”可用自己的示例文字逐个查看；未安装字体明确标注且不能冒充预览。坐标以 1920×1080 为基准，X/Y 指该行底边中心。长句可能换行，需检查双语是否互相遮挡。
6. 可读取保存好的 SVP，选择实际演唱轨，按原文和音符歌词提出时间锚点。结果要逐句勾选确认；原文/读音差异、延音、重复段和辅音提前量仍需试听。只改网页字幕时间，不改原文、译文、SVP 或音符。
7. 用空格从当前位置播放/暂停，I/O 标记循环区间，J/L 前后 2 秒。点击字幕编号跳转并选中单句样式。快速布局依赖浏览器字体与音频解码，声音只应用手动增益；准确预览用 FFmpeg/libass，最多 30 秒、720p，包含实际声音处理。修改后需新生成准确预览；旧预览保留其快照版本。
8. 在导出页选择原尺寸/1080高/720高、保留时间戳或固定帧率、MP4/MKV、H.264 CRF 和字幕烧录。音频 AAC 320 kb/s、48 kHz；MKV 是通用媒体封装，不是剪映原生工程。保留原视频长度，音频按偏移裁切/补静音，须检查结尾。

网页字幕使用本机 FFmpeg/libass 生成透明字幕层，与成片共用 ASS 字体、字号、描边、字间距、换行及坐标。字幕层按当前文字、样式和导出尺寸缓存，预取下一句；修改后自动更新，不需要先导出整段视频。旧请求不会覆盖后来修改的样式。缺少 FFmpeg 或排版失败时会明确标为“字幕近似显示”，应使用准确预览确认。准确预览播放的是已渲染快照；编辑后自动回到当前工程预览。

此机制统一字幕排版，不保证浏览器缩放、视频编码或不同播放器的色彩显示逐像素相同。缓存位于私有 `runtime/video-captions/`，最多保留 256 张，不改写歌词、字幕时间或已有成片。每次最多两个短字幕排版进程，退出保护覆盖处理中的请求。

音量策略可选手动增益加过采样峰值限制，或基于全段测量的两遍 `loudnorm`。匹配原视频响度可能改变混音动态；准确预览后再决定。输出会复测 AAC 编码后的 LUFS 与真峰值，真峰值高于 −0.5 dBTP 时给出提示。目标响度与处理器峰值参数不等于编码后必然精确达到的数值。

## 视频下方的字幕时间轴

预览视频下方提供全曲进度条，以及原文/译文两条字幕轨。色块表示持续时间，播放时高亮，点击可定位；完整原文与译文显示在轨道下方。默认“校对视图”每屏约 20 秒，避免长歌曲的字幕挤成一排；上方细进度条始终保留全曲定位。

用明显的“缩小 / 放大”按钮、缩放滑块或预设选择调整字幕轨，最大 64×，也能一键选择“全曲”。按钮和滑块缩放围绕当前播放位置；Ctrl + 滚轮围绕鼠标位置缩放。横向滚动或使用“前一屏 / 后一屏”浏览，底部显示当前可见时间范围；“定位播放头”回到试听位置。每个工程在本机浏览器记住缩放设置，缩放和浏览不会修改字幕时间或工程内容。

默认开启“跟随播放”：播放头接近当前屏幕右侧时，时间轴自动滚动；关闭后可自由浏览。手动滚动或翻屏会暂缓跟随 3 秒；“定位播放头”立即回到试听位置。这些开关与缩放设置一起按工程保存在本机浏览器。

拖动字幕块移动该行，拖左右边缘调整该行的开始/结束。默认只调整操作的原文或译文；开启“双语联动”才一起移动，已经存在的两行时间差会保留。键盘左右键微移 0.05 秒，Shift 配合左右键移动 0.5 秒。“边缘吸附”将拖动边缘轻轻对齐同一语言相邻字幕的起止或播放头，显示金色参考线；吸附距离不超过 8 像素或 0.12 秒，取较小者。按住 Alt 可临时关闭吸附，也可取消勾选长期关闭。

双击字幕块，或点击块内的铅笔按钮，直接修改这一行的文字；Enter / F2 也可打开编辑。修改即时更新当前预览，Ctrl + Enter 或“完成”收起，Esc /“取消”撤销本次文字编辑。编辑时暂停播放。独立时间会保存到工程，并用于网页预览、ASS 烧录与 SRT；SRT 将不同起止区间拆成不重叠的双语事件，以兼容普通播放器。

I/O 区域的两个手柄控制循环范围，独立于字幕时间。所有坐标使用视频秒数，准确预览片段也不会从零误当成全曲时间。时间与文字修改仍需点击“保存工程”；准确渲染结果保留提交时的快照，时间轴显示的是当前编辑稿。

### 撤销与重做

时间轴工具栏有“撤销 / 重做”按钮，也可用 **Ctrl + Z / Ctrl + Y**（或 Ctrl + Shift + Z）。范围包括字幕文字、单行/双语时间、整体改时、字幕增删、SV 时间锚点与字幕样式。一次拖动或一次时间轴文字编辑算一步；表格同一输入框中连续输入会合并。时间轴文字框内撤销会收起编辑框并撤销本次编辑；Esc 取消的文字不占历史，也不会破坏此前的重做。输入路径、搜索词等仍使用浏览器输入框自身的撤销。

撤销保留当前试听位置与缩放，不重新载入工程；保存后仍可撤销。回到已保存内容时显示“已保存”，撤销到其他内容则须再次保存才能用于后续任务。保存时音频偏移引起的字幕坐标变化也会同步到撤销记录，避免下次保存重复偏移。

记录仅留在当前页面，最多 100 步，并受内存预算限制；较大工程可能较早释放最旧记录。刷新、重新载入、切换工程或重新导入字幕会清空记录。撤销后开始新的修改会清空原有重做分支。页面历史与磁盘上的 `History/` 版本备份相互独立。

## 文档与版本

用户工程目录支持中文、日语和空格，内部工具目录沿用英文；真实内容均在忽略的 `projects/video/<name>/` 下：

| 位置 | 内容 |
| --- | --- |
| `project.json` | 当前工程、字幕、样式、素材引用与修订号 |
| `History/` | 每次保存前的配置；并发窗口的旧修订不能覆盖新修订 |
| `Sources/` | 导入字幕与旧配置的副本 |
| `Media/Video/视频标题.mkv` | 下载成功的视频，与本地导入的视频一起管理；也可能是 MP4 / WebM |
| `Tasks/Download 001/` | 下载任务快照、网站信息、日志与来源记录，不存放正式视频 |
| `Cache/Downloads/` | 下载中的临时文件；成功归档后清理本次缓存，失败/取消的缓存可保留排查 |
| `Jobs/Preview 001/` | 准确预览；分析使用 `Jobs/Analysis 001/` |
| `Exports/Export 001/` | 独立成片版本、ASS/SRT、配置与检查报告 |

新任务使用递增版本号，成片名为 `My Cover Video - v001.mp4`，再次导出另建 `Export 002` 和 `My Cover Video - v002.mp4`，不会覆盖已有版本。失败和取消的任务也保留编号。网页直接显示成片、双语字幕和“打开文件夹”，配置快照与技术报告默认收在“任务详情与检查报告”内。内部任务编号只用于定位，旧编号目录和旧视频下载链接仍兼容。

媒体通常引用原路径，不重复复制大文件。迁移设备时须一起搬运媒体并重新选择路径；`snapshot.json` 本身不是包含所有媒体的工程包。新下载的视频与任务记录分开，网页分别提供“打开素材文件夹”和“下载记录”。旧版 `Jobs/Download .../source.mkv` 及其历史记录继续有效，不自动移动、改名或改写工程引用；仍在使用的旧下载目录不能删。

导出完成前使用 `.rendering` 名称。只有整段解码、时长及输入哈希检查通过后才改为正式文件；每版报告记录实际规格、响度、真峰值与 SHA256。此类检查不能代替全片试听、翻译审校或视觉检查。

旧版 `video_config.toml` 可通过「导入现有配置」迁移，并读取相邻 `01_Project/project.json` 的媒体信息。已有已对齐 PCM 存在时优先使用，偏移/增益设为 0，避免重复处理；字幕时间与局部样式独立复制。原配置、原字幕和原成片保持不变。旧脚本中的长句字体宽度自适配不自动复刻，应检查准确预览。

任务单并发、最多 4 个排队/运行；可以取消当前或排队任务。运行中的下载、分析、渲染会阻止「彻底退出」，应完成或取消后退出。意外中断后，旧任务显示中断，不会自动重试。已经完成的成片不受影响。

## 部署与验证

基础导入、字幕编辑和手动对时无额外 Python 依赖；视频预览/导出需本机 FFmpeg（包含 libx264、libass、loudnorm）与 FFprobe，在「环境设置」配置。

下载和分段对时为可选安装：

```powershell
powershell -ExecutionPolicy Bypass -File tools/InstallVideoTools.ps1
```

安装的是 yt-dlp、NumPy、SciPy，不包含歌曲、视频或商业插件。网络下载的可用性由目标网站和本机网络决定；需要登录的视频请使用已有本地素材。核心程序不依赖这些可选库，也不自动安装。

```powershell
python tests/video-studio.py
python tests/video-studio.py --installed
python tests/portable-smoke.py --browser
```

第一项覆盖版本隔离、双语时间区间、ASS 文本安全、SV 锚点、并发修订、子进程取消及退出保护；第二项额外用合成媒体实际运行 FFmpeg 两遍响度、预览与导出。浏览器测试覆盖创建、文字/样式保存、重载与移动布局。测试不下载真实视频。

参考：[yt-dlp 官方说明](https://github.com/yt-dlp/yt-dlp)、[FFmpeg loudnorm](https://ffmpeg.org/ffmpeg-filters.html#loudnorm)、[FFmpeg ASS](https://ffmpeg.org/ffmpeg-filters.html#ass)。网页与本机服务不向云端上传媒体；下载链接会发送给你选择的网站。

## 界面集成与生命周期

主页面的 `workspace.js` 管理统一导航、视频工程列表与深链接。视频编辑器第一次进入时才创建同源嵌入实例，避免主页面和编辑器重复的元素编号、全局变量与样式互相影响；切换工作区保留同一实例，因此页面撤销历史和未保存编辑不会丢失。编辑器通过 `video/shell.js` 向主界面提供工程目录、状态与明确的导航/保存接口。

隐藏视频区时暂停试听与界面轮询，已提交的后台任务继续执行。环境设置保存后刷新视频区的依赖状态；整个应用只显示一个退出入口，退出通知也会停止嵌入编辑器。`/video/index.html?standalone=1` 保留为独立调试和测试入口；普通旧链接默认进入统一主界面。

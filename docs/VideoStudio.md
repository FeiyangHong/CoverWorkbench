# 视频制作工作区

从工作台「视频制作」进入，或打开本机 `/video/index.html`。这是独立的视频文档与任务工作区，不要求先导入音符校对试点。

## 分步引导与自动检查

页面顶部提供六步引导：获取 MV → 导入混音 → 对齐声音 → 双语字幕 → 预览检查 → 导出成片。点击步骤可查看缺项并直接定位操作；已有项目可收起说明，为预览留出空间。

检查包括素材路径、可选下载依赖、FFmpeg/FFprobe、字幕时间基准与双语内容，以及当前版本是否已有准确预览/成片。对齐试听和预览观看由用户明确确认，程序不会把相关度或任务成功当作人工审校。素材、偏移、字幕、样式或处理参数变化后，相应确认与预览会失效；未保存草稿也会参与缺项提示。

## 时间基准与重复偏移保护

- **混音时间导入**：只在导入时添加一次当前音频偏移，保存字幕来源及关联素材。以后同一素材的音频偏移改变，保存时只补新旧差值。例如原来 +5 秒改成 +7 秒，字幕只再移 +2 秒；重复保存不会再移动。
- **视频时间导入**：字幕固定在视频坐标，改变音频偏移不会移动字幕。
- **字幕整体微调**：独立的额外调整。若与已计入的音频偏移相同，会提示疑似重复，准确预览/导出前须清零或明确确认；整体改时也会拦截常见的重复添加。
- 更换或覆盖视频/混音、旧工程没有时间来源记录时，引导要求重新确认字幕基准。确认“现有字幕已是视频时间”只登记当前坐标，不会再加偏移。
- 已经处理成对齐视频的音轨，可标记并锁定音频偏移为 0。需要恢复原始音轨偏移时，先取消标记。
- 新导出的字幕附带 `caption-timing.json`。原样重新导入时会识别其已经是视频时间，拒绝再次作为混音时间叠加。文件被搬走且缺少边车信息时仍须自行选对基准，程序不能凭歌词文字推断所有历史处理。
- 重新导入从源字幕重新生成时间，并清零旧的字幕整体微调；历史工程保留。

## 一次制作

1. 新建英文工程名（可含空格）。同名自动使用 `_v2`、`_v3`，不会覆盖。选择原视频和最终翻唱混音，支持带引号的 Windows 路径与按时间排序的文件浏览器。
2. 可主动通过 yt-dlp 下载 YouTube / Bilibili HTTPS 视频链接。下载保存到该工程的任务目录；只有点击「使用下载的视频」才更新工程素材。下载不读取浏览器 Cookie，也不使用机器上的 yt-dlp 配置。网站限制与授权要求可能导致下载失败，可随时改用已有本地素材。
3. 「测量响度与分段偏移」比较原视频和翻唱。三个分段的多频带瞬态相关度给出固定偏移候选；结果不一致时须检查是否存在剪辑差异。此估计不是语音识别，也不是样本级同步保证，不会自动应用。正数表示混音延后。
4. 导入 UTF-8 LRC / SRT / VTT 原文与译文。LRC 的 `offset` 标签会计入，双语按独立时间区间配对，避免行数相同但实际错行。字幕若对齐混音，导入时加一次音频偏移；若已是视频时间，不加偏移。
5. 在表格修改字幕时间与文字。字体、字号、字间距、X/Y、颜色、加粗、描边、阴影可全局修改，也可覆盖单句。常见字体用“微软雅黑、黑体、宋体、楷体”等中文名称显示，点击“字形预览与选择”可用自己的示例文字逐个查看；未安装字体明确标注且不能冒充预览。坐标以 1920×1080 为基准，X/Y 指该行底边中心。长句可能换行，需检查双语是否互相遮挡。
6. 可读取保存好的 SVP，选择实际演唱轨，按原文和音符歌词提出时间锚点。结果要逐句勾选确认；原文/读音差异、延音、重复段和辅音提前量仍需试听。只改网页字幕时间，不改原文、译文、SVP 或音符。
7. 用空格从当前位置播放/暂停，I/O 标记循环区间，J/L 前后 2 秒。点击字幕编号跳转并选中单句样式。快速布局依赖浏览器字体与音频解码，声音只应用手动增益；准确预览用 FFmpeg/libass，最多 30 秒、720p，包含实际声音处理。修改后需新生成准确预览；旧预览保留其快照版本。
8. 在导出页选择原尺寸/1080高/720高、保留时间戳或固定帧率、MP4/MKV、H.264 CRF 和字幕烧录。音频 AAC 320 kb/s、48 kHz；MKV 是通用媒体封装，不是剪映原生工程。保留原视频长度，音频按偏移裁切/补静音，须检查结尾。

网页字幕使用本机 FFmpeg/libass 生成透明字幕层，与成片共用 ASS 字体、字号、描边、字间距、换行及坐标。字幕层按当前文字、样式和导出尺寸缓存，预取下一句；修改后自动更新，不需要先导出整段视频。旧请求不会覆盖后来修改的样式。缺少 FFmpeg 或排版失败时会明确标为“字幕近似显示”，应使用准确预览确认。准确预览播放的是已渲染快照；编辑后自动回到当前工程预览。

此机制统一字幕排版，不保证浏览器缩放、视频编码或不同播放器的色彩显示逐像素相同。缓存位于私有 `runtime/video-captions/`，最多保留 256 张，不改写歌词、字幕时间或已有成片。每次最多两个短字幕排版进程，退出保护覆盖处理中的请求。

音量策略可选手动增益加过采样峰值限制，或基于全段测量的两遍 `loudnorm`。匹配原视频响度可能改变混音动态；准确预览后再决定。输出会复测 AAC 编码后的 LUFS 与真峰值，真峰值高于 −0.5 dBTP 时给出提示。目标响度与处理器峰值参数不等于编码后必然精确达到的数值。

## 视频下方的字幕时间轴

预览视频下方提供全曲进度条，以及原文/译文两条字幕轨。色块表示持续时间，播放时高亮，点击可定位；完整原文与译文显示在轨道下方。默认“校对视图”每屏约 20 秒，避免长歌曲的字幕挤成一排；上方细进度条始终保留全曲定位。

用明显的“缩小 / 放大”按钮、缩放滑块或预设选择调整字幕轨，最大 64×，也能一键选择“全曲”。按钮和滑块缩放围绕当前播放位置；Ctrl + 滚轮围绕鼠标位置缩放。横向滚动或使用“前一屏 / 后一屏”浏览，底部显示当前可见时间范围；“定位播放头”回到试听位置。每个工程在本机浏览器记住缩放设置，缩放和浏览不会修改字幕时间或工程内容。

默认开启“跟随播放”：播放头接近当前屏幕右侧时，时间轴自动滚动；关闭后可自由浏览。手动滚动或翻屏会暂缓跟随 3 秒；“定位播放头”立即回到试听位置。这些开关与缩放设置一起按工程保存在本机浏览器。

拖动字幕块移动该行，拖左右边缘调整该行的开始/结束。默认只调整操作的原文或译文；开启“双语联动”才一起移动，已经存在的两行时间差会保留。键盘左右键微移 0.05 秒，Shift 配合左右键移动 0.5 秒。“边缘吸附”将拖动边缘轻轻对齐同一语言相邻字幕的起止或播放头，显示金色参考线；吸附距离不超过 8 像素或 0.12 秒，取较小者。按住 Alt 可临时关闭吸附，也可取消勾选长期关闭。

双击字幕块，或点击块内的铅笔按钮，直接修改这一行的文字；Enter / F2 也可打开编辑。修改即时更新当前预览，Ctrl + Enter 或“完成”收起，Esc /“取消”撤销本次文字编辑。编辑时暂停播放。独立时间会保存到工程，并用于网页预览、ASS 烧录与 SRT；SRT 将不同起止区间拆成不重叠的双语事件，以兼容普通播放器。

I/O 区域的两个手柄控制循环范围，独立于字幕时间。所有坐标使用视频秒数，准确预览片段也不会从零误当成全曲时间。时间与文字修改仍需点击“保存工程”；准确渲染结果保留提交时的快照，时间轴显示的是当前编辑稿。

### 撤销与重做

时间轴工具栏有“撤销 / 重做”按钮，也可用 **Ctrl + Z / Ctrl + Y**（或 Ctrl + Shift + Z）。范围包括字幕文字、单行/双语时间、整体改时、字幕增删、SV 时间锚点与字幕样式。一次拖动或一次时间轴文字编辑算一步；表格同一输入框中连续输入会合并。时间轴文字框内撤销会收起编辑框并撤销本次编辑；Esc 取消的文字不占历史，也不会破坏此前的重做。输入路径、搜索词等仍使用浏览器输入框自身的撤销。

撤销保留当前试听位置与缩放，不重新载入工程；保存后仍可撤销。回到已保存内容时显示“已保存”，撤销到其他内容则须再次保存才能用于后续任务。保存时音频偏移引起的字幕坐标变化也会同步到撤销记录，避免下次保存重复偏移。

记录仅留在当前页面，最多 100 步，并受内存预算限制；较大工程可能较早释放最旧记录。刷新、重新载入、切换工程或重新导入字幕会清空记录。撤销后开始新的修改会清空原有重做分支。页面历史与磁盘上的 `History/` 版本备份相互独立。

## 文档与版本

所有目录名为英文，真实内容均在忽略的 `projects/video/<name>/` 下：

| 位置 | 内容 |
| --- | --- |
| `project.json` | 当前工程、字幕、样式、素材引用与修订号 |
| `History/` | 每次保存前的配置；并发窗口的旧修订不能覆盖新修订 |
| `Sources/` | 导入字幕与旧配置的副本 |
| `Jobs/Preview 001/` | 准确预览；下载和分析分别使用 `Download 001`、`Analysis 001` |
| `Exports/Export 001/` | 独立成片版本、ASS/SRT、配置与检查报告 |

新任务使用递增版本号，成片名为 `My Cover Video - v001.mp4`，再次导出另建 `Export 002` 和 `My Cover Video - v002.mp4`，不会覆盖已有版本。失败和取消的任务也保留编号。网页直接显示成片、双语字幕和“打开文件夹”，配置快照与技术报告默认收在“任务详情与检查报告”内。内部任务编号只用于定位，旧编号目录和旧视频下载链接仍兼容。

媒体通常引用原路径，不重复复制大文件。迁移设备时须一起搬运媒体并重新选择路径；`snapshot.json` 本身不是包含所有媒体的工程包。下载的素材保留在 Jobs 内，因此仍在使用的下载目录不能删。

导出完成前使用 `.rendering` 名称。只有整段解码、时长及输入哈希检查通过后才改为正式文件；每版报告记录实际规格、响度、真峰值与 SHA256。此类检查不能代替全片试听、翻译审校或视觉检查。

旧版 `video_config.toml` 可通过「导入现有配置」迁移，并读取相邻 `01_Project/project.json` 的媒体信息。已有已对齐 PCM 存在时优先使用，偏移/增益设为 0，避免重复处理；字幕时间与局部样式独立复制。原配置、原字幕和原成片保持不变。旧脚本中的长句字体宽度自适配不自动复刻，应检查准确预览。

任务单并发、最多 4 个排队/运行；可以取消当前或排队任务。运行中的下载、分析、渲染会阻止「彻底退出」，应完成或取消后退出。意外中断后，旧任务显示中断，不会自动重试。已经完成的成片不受影响。

## 部署与验证

基础导入、字幕编辑和手动对时无额外 Python 依赖；视频预览/导出需本机 FFmpeg（包含 libx264、libass、loudnorm）与 FFprobe，在「环境设置」配置。

下载和分段对时为可选安装：

```powershell
powershell -ExecutionPolicy Bypass -File tools/InstallVideoTools.ps1
```

安装的是 yt-dlp、NumPy、SciPy，不包含歌曲、视频或商业插件。网络下载的可用性由目标网站和本机网络决定；需要登录的视频请使用已有本地素材。核心程序不依赖这些可选库，也不自动安装。

```powershell
python tests/video-studio.py
python tests/video-studio.py --installed
python tests/portable-smoke.py --browser
```

第一项覆盖版本隔离、双语时间区间、ASS 文本安全、SV 锚点、并发修订、子进程取消及退出保护；第二项额外用合成媒体实际运行 FFmpeg 两遍响度、预览与导出。浏览器测试覆盖创建、文字/样式保存、重载与移动布局。测试不下载真实视频。

参考：[yt-dlp 官方说明](https://github.com/yt-dlp/yt-dlp)、[FFmpeg loudnorm](https://ffmpeg.org/ffmpeg-filters.html#loudnorm)、[FFmpeg ASS](https://ffmpeg.org/ffmpeg-filters.html#ass)。网页与本机服务不向云端上传媒体；下载链接会发送给你选择的网站。

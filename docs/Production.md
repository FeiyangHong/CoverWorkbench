# 制作主页与 MSST 接入

推荐流程是 **MSST 分离 → SV 制作 → Studio One 混音 → 工作台字幕与视频**。网页负责管理素材和衔接工具，不要求在网页逐音符修改或控制 SV。

## 为一首歌接上已有工作

导入已保存的 SVP 后，打开「项目主页 → 管理文件路径」，登记实际使用的 SVP、Song、原歌曲、主声、可选和声、伴奏和成品混音。支持带引号的 Windows 路径、文件浏览、复制路径和文件管理器定位。打开工程只请求原生软件加载磁盘文件，不自动保存或改写。

默认会读取工程原有素材；Song 和伴奏只根据已保存构建记录中的 SVP 路径精确匹配，不凭同名歌曲猜测。可以随时登记实际使用的新文件。登记 SVP 只影响后续打开和交接，不会重新解析历史音符或替换 SV 内容。

「建混音工程」自动带上已登记的 SVP 与伴奏，再由你确认声部、模板和输出位置。已有 Song 可直接打开，避免重复搭建。成品混音会作为新视频的默认候选；若在关联窗口手动固定了另一份混音，需在那里切回自动选取或换成新文件。

音乐与视频只需关联一次。已有视频的字幕、样式、音频偏移、任务记录和导出版本都继续保存在原工程；仅建立关联、登记文件或进入视频不会覆盖它们。正式字幕请在视频区编辑。音乐侧字幕草稿是可选历史功能，不与视频双向自动同步。

「检查成品音频 / 整理交付包」是可选折叠工具；不需要测量和打包时直接进入视频。主页的“已登记”表示文件存在，不代表创作、混音或对时已经人工检查完毕。

## 接入自己的 MSST

1. 单独安装 [MSST-WebUI](https://github.com/SUC-DriverOld/MSST-WebUI) 与所需模型。
2. 在「素材分离 → 服务设置」填写它的本机 HTTP 地址，例如 `http://127.0.0.1:7860`。可选择已安装的 EXE 或桌面 LNK 快捷方式作为启动入口；也可留空并自行启动。
3. 点击「启动 MSST」后检查连接。模型选择和分离操作继续使用 MSST 原界面。启动程序自动切换端口时，填写它实际显示的地址；工作台不修改 MSST 配置。
4. 可「新标签页打开」，也可明确点击「在工作台内打开」。嵌入只在点击后加载，不代理或复制第三方代码；若该页面限制 iframe，请使用新标签页。MSST 独立管理任务，工作台不伪装成已经完成分离。
5. 分离后点「登记分离结果」，选主声、和声与伴奏路径。复制原歌曲路径可以帮助在 MSST 中定位输入；浏览器隔离使工作台不会偷偷填充外部页面的文件上传框。

不自动启动 MSST，不自动下载模型，也不在未进入分离页时轮询该服务。正常空闲流程不运行 SV 实时轮询；实验功能需主动启用。

工作台的“彻底退出”结束自己的后台，不关闭独立 MSST 进程。分离任务的进度和结束应在 MSST 窗口确认，不使用时单独退出 MSST。关闭嵌入页也不等于关闭该进程。

## 本机配置与迁移

MSST 地址和启动位置保存在 `config/settings.local.json`；每首歌的文件登记保存在 `config/project-assets.local.json`，前一版在 `.previous.json`；音乐/视频关联保存在 `config/video-links.local.json`。均被 Git 忽略。

新设备先安装自己的工具、配置本机位置，再导入或登记素材。仓库不附带 MSST、模型、歌曲、个人工程和付费软件。服务地址仅接受回环 HTTP；不会通过探测跟随外部重定向，也不使用环境代理。

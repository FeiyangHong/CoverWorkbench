# 工程保护、搬家与制作预设

主页面右上角和视频编辑器中的 **工程管理** 提供工程包、成品版本和磁盘空间管理。视频编辑器另外提供自动草稿恢复与 **制作预设**。这些操作不会迁移或改名已有工程。

## 自动草稿与恢复

视频编辑时，浏览器先保存本地草稿，停止输入约 750 毫秒后同步为本机服务器的独立草稿。页面会显示保存状态；草稿位于视频工程的 `Recovery/Draft 001.json` 等文件中，与正式的 `project.json` 分开。

- 刷新或重新进入工程后，恢复提示可将草稿放回编辑器，检查后再按 **Ctrl+S** 正式保存；恢复本身可以撤销。
- 另一窗口已经保存了新版本时，旧草稿只能恢复为独立的 ` - Recovered` 副本，避免覆盖新内容。
- 保存工程、撤销回已保存状态会归档本会话草稿。忽略草稿也保留归档记录。
- 恢复副本使用草稿原来的时间基准，避免音频偏移再次叠加到字幕上。

自动草稿只涵盖工作台的视频编辑内容。SV、Studio One 内尚未保存的内容仍需在各自软件中保存。浏览器清理存储可能删除尚未同步成功的浏览器草稿，请留意状态文字。

## 完整工程包与新设备导入

在音乐工程选择 **工程管理 → 备份与搬家 → 生成完整工程包**，会生成可下载的 `.cwpack` 文件。它是带文件校验清单的 ZIP 包；后台输出位于 `work/Project Packages/Task 001/` 等可读目录。

打包前，先在 SV / Studio One 和工作台中保存。打包期间暂停编辑相关文件；文件发生变化或当前使用的素材缺失时，任务会失败并保留原工程。

工程包收集本曲目录、登记素材、关联的视频工程、字幕、样式、成品版本，以及能够解析的 SV 音频引用、Song 媒体引用和 SV 插件工程链接。外部依赖会复制到包内，原文件保持原位。缓存、下载任务记录、恢复草稿、程序与模型本体不打包；当前使用的媒体即使位于旧任务目录，也会单独收集。历史缺失引用会列出提示。

在工作台选择 **导入工程包**，输入路径或浏览文件，可指定新的项目目录名。系统逐个校验文件，在 `projects/` 下创建新副本，并重建已知文件引用和本机登记。已有同名目录另存 `_v2` 等版本，不覆盖旧工程。导入失败时，不完整副本留在任务目录中，不登记为正常工程。

新设备仍需安装相应声库、商业插件、字体和工具。工程包列出字幕字体要求；商业插件内部无法解析的外部资源仍应先在原生软件中归集。包内包含歌曲和媒体，仅供你自行保管，不会自动上传 GitHub。导入需要约两份工程大小的临时空间。

导入保留字幕时间、样式与音频偏移，但新路径会要求重新确认对齐并做准确预览。工程包是已保存内容的快照，不是运行中软件状态的镜像。

## 成品版本与来源

在 **工程管理 → 成品版本** 选择混音或成片，填写说明并选择 **试用 / 定稿 / 已发布**。保存后会复制到本工程的 `exports/releases/Mix 001/` 或 `Video 001/`，后续覆盖原导出文件不会改变这个版本。你可以改变版本阶段、打开文件位置，或明确将某版混音选入当前工程。

版本复制会额外占用磁盘。定稿与已发布操作会重新校验文件；工作台不会让这些操作覆盖版本内容。文件被外部修改后会显示变化，需要重新保存独立版本。

视频区显示已保存工程使用的混音版本和字幕工程修订号。准确预览与正式导出的报告还记录实际输入的校验信息、混音版本、字幕修订和字幕内容签名；字幕签名用于核验，不作为文件夹名称展示。没有登记过的音源会明确显示尚未标记版本，已有旧成片不会凭空补造来源。

## 磁盘统计与可恢复清理

在 **工程管理 → 磁盘空间 → 扫描磁盘占用** 查看当前工程分类占用。只有明确扫描时才统计，不会常驻遍历磁盘。

可选清理项限于能重新生成的连续缩略图、网页代理、字幕排版缓存和已完成的区间预览。原媒体、已登记为输入的文件、SV / Song、恢复草稿和正式成片不作为缓存候选；历史迁移备份只提供查看入口。

1. 勾选缓存，点击 **隔离所选缓存**。文件移到 `work/Recoverable Cleanup/Batch 001/` 等可恢复区，仍占用磁盘。
2. 如需找回，点击 **恢复**。原位置若已有新缓存会拒绝覆盖。
3. 确认不再需要后，点击 **永久删除并释放空间**，再次确认后才删除隔离副本。此操作不可恢复。

共享缓存可能被多首歌曲复用；隔离后会按需重建。操作前暂停试听并等待后台任务结束；缓存内容变化后需要重新扫描。

## 复用字幕与导出预设

视频编辑器的 **制作预设** 可套用内置的中日、中英字幕设置，也可将当前设置保存为自定义预设，供其他工程使用。它保存双语全局字体、位置、间距与样式，以及分辨率、帧率、格式、CRF、是否烧录字幕。

套用进入当前草稿并产生一次可撤销操作，不改变字幕文字、字幕时间、音乐、音量、偏移或视频片段。逐句自定义样式继续保留，可能覆盖全局样式；应用前确认本机已安装所选字体。自定义预设保存在 `config/production-presets.local.json`，不会上传到源码仓库。

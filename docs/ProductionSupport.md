# 制作助手：队列、文件交接、检查和备份

主页面右上角的 **制作助手** 统一提供以下入口。SV 的音符、歌词、音高和声线继续在原生软件中编辑；这里管理文件与交付。

## 分离队列

先在 **素材分离** 页选择模型、流程和参数，再到 **制作助手 → 分离队列** 勾选歌曲。输入使用每首歌登记的原曲，逐首校验并顺序运行，不并发争用显卡。每首最多有一个未完成任务，队列最多 20 首。

支持回调的 PyMSS 环境显示当前阶段、真实处理进度、本阶段预计剩余时间和整卡显存采样；预计时间会波动，整卡数据包含其他软件。旧环境或旧 MSST 只显示可获得的阶段信息，不模拟百分比。校验登记完成前不会显示整个任务已完成。

排队期间输入或模型改变时，任务会拒绝悄悄使用新版。取消尚未运行的任务不会开始推理。异常退出后，可点击 **恢复上次未开始的队列**；已经开始的任务通过后台任务中的重试操作处理，可验证的第一阶段输出可复用。这不是任意音频帧的断点恢复。

默认仍为 DeUX → Frazer、87.5% 重叠、batch 4、TTA 关闭。旧 MSST 保留为备选。

## 文件交接

工作台运行时，以较低频率检查登记的 SVP、Song 和本曲导出目录的文件大小与修改时间；连续检查稳定至少 3 秒才提示。首次建立观察记录，不把所有旧文件都视为新版本。原生软件返回前应先完成保存或导出；某些软件长时间暂停写入也可能被判断为稳定，因此接入仍由你确认。

- **确认这个保存版本**：确认 SV / Studio One 的保存记录，不改动工程内容。
- **复制到项目并登记为成品混音**：保留源文件，用项目内副本接入。
- **保存视频草稿并带入混音**：只更新关联视频的音频，保留字幕文字、样式、画面剪辑和已有偏移。其他窗口中的草稿也应先保存。

旧的素材基准对比仍可从该页进入。可以关闭自动观察；不会改变已登记文件。

## 音乐检查

选择 Studio One 导出的混音，开始后台分析。报告包括综合响度、真峰值、响度范围、持续静音、明显声道电平差异、与已登记伴奏的时长差异，以及末端仍有声音的情况。

点击疑点可在原音频上定位试听；真峰值为整曲测量，定位使用最大采样峰值附近作参考。它不是精确的每个插值峰值定位。有意的静音、声像或结尾硬切可以标记为 **有意保留**。更换文件后报告与忽略记录会失效。检查不改增益、不压缩、不删除静音，也不以某个 LUFS 数值作为平台强制要求。支持最长两小时音频，需 FFmpeg / FFprobe。

## 跨盘增量备份与恢复

在 **备份恢复** 中选择与工作区不同盘符的专用文件夹、需要保护的歌曲和间隔。自动计划仅在工作台后台运行时执行；彻底退出后没有额外驻留服务，下次启动会补做已到期计划。备份失败后暂停该歌曲的自动重试，并保留原因；重启或重新保存计划不会清除失败状态。修复缺失素材等问题后，点击 **立即备份当前歌曲**，成功后恢复该歌曲的自动计划。其他歌曲的备份不受影响。

每首歌使用可读目录：

```text
Backup Drive/
  Artist - Song/
    Owner.json
    Backup 001/
      Manifest.json
      Files/...
    Backup 002/
      Manifest.json
      Files/...   # 只新增发生变化的文件
```

备份沿用工程打包的依赖收集与路径重定位逻辑，包含已解析的外部音频、SVP、Song、歌词和关联视频编辑记录，排除可再生成缓存。未变化文件引用先前备份，因此 **请保留整个歌曲备份目录，不单独删除早期版本**。当前实现每次仍会读取与校验工程，不承诺只扫描变化文件。

备份只在复制、哈希校验和完整清单写入后发布。正常捕获的失败或取消会清理任务的 `Working Copy` 和未发布的 `Preparing Backup ...`，保留任务记录及已发布版本。断电或强制结束进程可能留下临时目录，需要核对任务状态后清理。Whisper 下载模型缓存不随工程打包。先执行 **校验**，再选择 **恢复副本**：它会创建新身份和新目录，复原并重定位引用，不覆盖当前工程。声库、商业插件、字体和软件本体仍需在恢复设备安装；插件内部未能解析的外部依赖，以备份警告和原生软件检查为准。

## 运行版本与更新

**运行版本** 分别显示桌面启动器、后台与工作区源码版本；后台代码或网页资源与磁盘不同会提示保存后重启或重新加载。

可信源码 ZIP 可以选择 **空闲时应用**：记录包的哈希，等待后台任务结束后按原有源码更新机制备份并应用，不覆盖个人配置与项目。等待期间包改变会拒绝应用；应用后仍由你保存草稿并重启。当前打包后台不会覆盖运行中的 EXE；桌面便携版应解压到新目录，退出旧版后指向原工作区。更新与回退仍可在 **环境更新** 中查看。

# 制作助手

主页面右上角的 **制作助手** 汇总后台任务、成片检查、素材更新、环境诊断与快捷操作。视频编辑器同时提供 **成片检查** 按钮。音乐与视频原有保存、撤销和时间轴继续使用，已有工程不需要迁移。

## 后台任务

下载、MSST 分离、网页代理、视频预览、导出、工程包、插件试听与交付任务集中展示，可按当前工程、处理中或失败过滤。关闭助手弹窗不会取消任务；打开时才刷新列表，不进行常驻文件扫描。

支持明确取消和失败重试。重试采用当前已保存的素材与环境，创建新结果，保留旧任务；工程更换素材后应先核对再确认。旧版工程包任务没有保存重试参数时，需要重新在工程管理中提交。插件试听、交付和各工具任务保留自身的超时与错误信息。

视频渲染、代理、原生插件试听、成片检查和 MSST 分离共用一个重型计算通道，避免同时挤占机器；下载可独立进行。排队任务可以取消。短暂的网页字幕图层或波形预览仍使用有界的交互处理通道。

两步 MSST 流程会在 big7 完成后写入阶段记录。第二步失败时重试，只有原输入内容、第一步模型/配置记录和输出校验均符合，才把已完成的人声、伴奏复制到新任务，直接继续 karaoke。源文件、模型或结果变化时会重新计算或拒绝复用，不会把未完成结果登记成正常素材。

## 成片检查

点击 **保存并开始后台检查**。检查对象是当前已保存的视频工程，包括：

- 字幕时间、相邻重叠、显示过短、长句、缺少译文和超出成片结尾。
- 字体是否可用，提示可能的替代字体。
- 混音尾部是否会被成片长度截断。
- 以相同 FFmpeg/libass 渲染路径抽样检查字幕贴边、裁切、不可见和双语字形范围重叠。

所有字幕检查文字与时间；最多 40 句按长句和不同样式抽样渲染。排版采样使用 960×540，对应同一套 1920×1080 字幕坐标。提示是辅助复核，不能证明翻译、听感、所有字体字形或整片画面完全正确；有意叠放字幕、缺省译文等可以人工确认。

点击问题直接选择对应字幕并跳到时间点。修改字幕、样式、音源或覆盖素材后，报告会标为过期。报告保存在视频工程 `ProjectData/Latest Check.json`，具体任务保留独立报告。

## 素材更新与影响

在 **素材更新** 页先为歌曲记录当前素材基准。以后保存 SVP、Song、混音或替换分离文件后，可比较已登记路径、大小与修改时间，查看受影响的后续步骤。视频保存时记录其使用的源版本；切回工作台时会按需检查并显示更新入口。

该比较不是全文件内容哈希：如果外部工具刻意保留大小与修改时间，可能无法发现变化。它也不会自动替换音轨、重新生成歌词或叠加偏移。使用 **选择是否带入新混音 / 字幕** 进入已有的关联更新窗口，分别确认要更新的内容；精修字幕可保留。记录新基准不会改变原媒体。

## 环境诊断与源码更新

诊断在后台检查 FFmpeg/FFprobe 的启动、libass 支持、原生工具配置、可选依赖和工作区写入权限。报告 ZIP 只含结构化检查结果，不包含歌曲、歌词、个人配置、完整路径、原始任务日志或账号信息；分享前仍可自行打开查看。

源码更新需要手动选择可信的 CoverWorkbench 源码 ZIP，并明确确认。仅处理公开的程序目录和配置示例，不覆盖 `projects/`、`data/`、`runtime/`、`config/*.local.*` 等个人数据；变更前备份到 `work/Source Updates/Update 001/`。回退会核对更新后的文件，若源码又被手工修改，则保留备份并拒绝覆盖。新版本若有额外依赖，仍需按其说明安装；此功能不是依赖安装器或桌面 EXE 自更新器。

## 统一操作

| 按键 | 功能 |
| --- | --- |
| Ctrl+Shift+P | 可搜索的操作面板 |
| Ctrl+Alt+T | 后台任务 |
| F1 | 快捷操作说明 |
| Ctrl+S | 保存工作台视频工程 |
| Ctrl+Z / Ctrl+Y | 视频撤销 / 重做 |
| 空格、J / L、I / O | 现有视频播放、跳转、区间标记 |

文字编辑保留原有输入行为。新管理窗口共用文件选择器：支持带引号路径、Enter 前往/选择、修改时间排序与打开所在文件夹。多选媒体等专门操作继续使用各自的素材选择器。

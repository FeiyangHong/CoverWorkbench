# 混音指南 / Mixing guide

在工作台顶部选择 **混音指南**。新安装即能使用，无需先导入歌曲。也可以打开独立页面：<http://127.0.0.1:8765/mix-guide/index.html>，放在 Studio One 旁边对照。

## 如何使用

1. 在左侧搜索或选择声音问题，例如“混响拖尾太长”“回声重复太久”“人声闷”。支持空间、延迟、音色和动态四类目标。
2. 阅读对应的 Studio One 操作路径、建议动作、试调起点，以及调整后应该听什么变化。
3. 默认对照清晰的 SVG 控件教学图。点击编号或参数卡查看说明；切换“实拍局部对照”可核对实际界面，局部截图按原始像素限制尺寸。
4. 用“完整界面”按需打开原始截图；100% 对应原始像素，继续放大不增加截图细节。支持滚动和 Esc 关闭。手动浏览其他插件后，可以回到目标图示。
5. 在“用自己的声音，听真实 FabFilter”中选择分离人声和区间，生成真实插件 A/B；也可用“先听一听”中的浏览器教学示例。再在 Studio One 中完成实际调整。指南不会改写 Song、SVP 或已打开的插件实例。

当前包含 18 个问题入口、5 个插件的本机截图，以及一张单独标明的 Studio One 插入／发送／返回路由示意图。数值是练习起点，不代表对某首歌曲试听后的结论。

## 真实 FabFilter 人声试听

首次使用需要可选引擎，在工作台目录运行：

```powershell
.\tools\InstallNativeAudio.ps1
```

同时需要在环境设置配置 FFmpeg / FFprobe，并自行安装、授权 **FabFilter Pro-R 2、Timeless 3、Pro-Q 3 的 Windows VST3 版本**。可只安装需要的插件。安装完成后刷新网页即可；普通指南与浏览器教学不依赖这个引擎。标准位置为系统 Common Files 下的 `VST3/FabFilter`；自定义位置可在启动服务前设置 `COVERWORKBENCH_VST3_DIR`，指向直接包含这些 `.vst3` 的文件夹。

1. 粘贴本机分离人声路径，或点“浏览文件”选择。接受 WAV、FLAC、AIFF 和外层引号；浏览器支持修改时间、名称、大小排序与驱动器切换。点“读取音频”查看完整时长。优先使用纯主唱，也可以用 SV 导出的干人声。
2. 输入开始／结束时间，支持秒数与 `mm:ss`，例如 `45`、`1:15.5`。每段 0.25–30 秒；另留 2／4／8 秒尾音。15／30 秒按钮只改变区间，不会自动播放。
3. 选择插件与参数。混响、回声支持“干声→加效果”，也支持长／短 Space 或反馈对比；EQ 提供单个 Bell／High Shelf 频段。
4. 点击“生成真实 A/B”。服务用独立进程加载本机 VST3，以 48 kHz 双声道离线渲染，最多读取区间前 2 秒作为效果预热，再输出相同长度的 A/B。渲染超时或插件失败会明确报错，不会降级成浏览器算法。
5. 点击播放后可连续切换 A/B、暂停、拖动、回到片段开头、循环和调节音量。默认音量 35%，可选近似 RMS 匹配。参数改变后旧试听失效，需要重新生成；隐藏网页或切换工作台页面会暂停。真实插件与浏览器教学不会同时播放。

**参数与边界：** 页面展示插件实际回读值，宿主的参数搜索存在微小量化误差，以回读为准。Space 与实际尾音长度并不完全相同，还受 Decay Rate / Decay EQ 影响。此功能从独立插件的默认状态开始试调，不载入 Studio One 的预设、发送、伴奏、总线或整条混音链，也不会同步参数到 DAW。实际混音请带伴奏复核。额外尾音是固定长度，长尾可能需要选择 8 秒；循环会包含尾音。EQ 固定 Zero Latency 模式。

**本机文件管理：** 人声只读，路径通过回环接口交给本机服务，不向外部站点上传。每次任务的请求、插件回读、日志和两路 WAV 分别保存在被 Git 忽略的 `runtime/mix-auditions/<id>/`。任务链接仅在本次服务运行期间有效；重启后重新生成即可。试听缓存不会自动写入创作工程，需要空间时可在停止试听与渲染后清理该目录。不要把运行目录加入公开发行包。

## 浏览器教学试听

- 提供干声／混响、长尾／短尾、干声／回声、长反馈／短反馈，以及 EQ 对比。
- A/B 共用播放位置，切换时使用短交叉淡化。支持暂停、回到开头、拖动进度、循环和独立音量。
- 调节尾音时间、预延迟、效果量、延迟间隔、反馈、EQ 频率／增益／Q。EQ 提供 Bell 与 High Shelf；空气感与低中频问题会载入相应的起始频段。
- 默认使用代码生成的原创合成哼唱或拨弦，无歌曲、歌词、录音或声库。可选择本地短音频，仅在浏览器内解码，不上传、不保存；限制 50 MB，使用开头最多 10 秒，并留出最多 4 秒效果尾音。
- 示例采用通用 Web Audio 卷积混响、延迟和 Biquad EQ，**不是 FabFilter 插件渲染，也不模拟具体预设**。参数用于理解变化方向，不表示在原插件中会得到相同音色。当前试听覆盖混响、回声和 EQ；动态与齿音仍提供图文指南。
- 音量匹配使用近似 RMS，而非 LUFS；两路共享峰值留量，播放音量默认为 35%。切换工作台页签、隐藏网页或离开页面会暂停教学试听。

## 维护与验证

页面、浏览器音频处理和图示位于 `app/static/mix-guide/`；应用内和独立页面共用同一份内容。新增或更换截图时必须重新核对裁剪范围和百分比标记坐标。原创矢量控件图可通过 `python tools/render_mix_controls.py` 生成；对应坐标保存在 `diagrams/positions.json`，修改布局时需同时更新 `guide.js` 的 `clearPositions`。

浏览器验证包含空工作区入口、所有图示加载、参数联动、搜索／分类、放大／Esc 与焦点恢复、移动端溢出，大屏实拍图不拉伸、本地音频不上传、A/B 保持时间线、效果差异／尾音能量／音量匹配／峰值留量，以及教学操作不发送工程修改请求：

```powershell
npm ci
$env:CW_BROWSER_CHANNEL='msedge'
python tests/portable-smoke.py --browser
```

CI 使用 Playwright Chromium；Edge 选项只用于本机已有浏览器。指南的说明与插图可离线加载，打开“官方参数说明”链接时才访问外部网站。

真实插件验证单独运行，不要求公共 CI 安装商业插件：

```powershell
python tests/native-audio.py
# 仅在本机已安装并授权插件时：
python tests/native-audio.py --installed
```

后者使用合成测试音检查三款实际插件、参数回读、两种效果前后对比、尾音、峰值留量、EQ 脉冲对齐及输入哈希不变。它证明渲染与播放链路可工作，不代表对某首作品的主观混音质量评价。
